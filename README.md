# ⭐ 헤라클레스의 열두 별

초등 저학년을 위한 2.5D 액션 RPG. 꼬마 영웅 헤라클레스가 **12과업**을 해내고 별 12개를 모아 밤하늘의 별자리가 되는 이야기입니다.
**원작 시나리오: 우리 아이** — 아이가 직접 쓴 12과업 문장이 게임의 뼈대입니다.

- 📖 시나리오: [docs/SCENARIO.md](docs/SCENARIO.md)
- 🎮 게임 디자인 · 조작 · 타격감: [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)
- 🎨 애셋 명세 (Codex 작업용): [docs/ASSET_SPEC.md](docs/ASSET_SPEC.md)
- 🤖 작업 지침 (Claude · Codex): [AGENTS.md](AGENTS.md)

## 실행

```bash
npm install
npm run dev
```

- PC: 터미널에 나온 `Local` 주소 (http://localhost:5173)
- **휴대폰**: PC와 같은 Wi-Fi에서 터미널에 나온 `Network` 주소 (예: http://192.168.0.10:5173) 로 접속
  - 안드로이드: 시작 버튼을 누르면 전체 화면 + 가로 고정
  - 아이폰: Safari **공유 → 홈 화면에 추가** 후 홈 화면 아이콘으로 열면 전체 화면

## 배포 (인터넷 어디서나)

```bash
npm run build
```

`dist/` 폴더를 GitHub Pages · Netlify · Vercel 등 정적 호스팅에 올리면 됩니다 (상대 경로라 어느 주소에서도 동작).

## 조작

| 휴대폰 | 키보드 | 동작 |
|---|---|---|
| 왼쪽 화면 드래그 | WASD / 방향키 | 이동 |
| 큰 버튼 | J / Space | 공격(3단 콤보) · 말하기 · 꽉 잡기 |
| 바람 버튼 | K / Shift | 구르기 (무적) |
| 스킬 버튼 | L | 독화살 · 딸랑이 · 창 |
| ↻ | Q | 스킬 바꾸기 |
| ⏸ | Esc | 메뉴 (지도 · 도감 · 설정) |

## 개발용 주소 옵션

| 옵션 | 설명 |
|---|---|
| `?stage=labor05` | 해당 스테이지로 바로 (hub, prologue, labor01~12) |
| `?gallery` | 스프라이트 · 아이콘 · 그림책 그림 전체 보기 (애셋 확인) |
| `?god` | 무적 |
| `?auto` | 대화 · 연출 자동 넘김 |
| `?bot` | 자동 플레이 봇 (테스트) |
| `?sim` | 창이 숨겨져도 게임이 계속 돎 (테스트) |
| `?fps` | 프레임 · 드로우콜 표시 |

예: `?stage=labor02&auto&god&bot&sim` → 과업 2를 봇이 끝까지 플레이.

부모님 메뉴(설정 → 모든 과업 열기)로 아무 과업이나 바로 할 수 있습니다.

## 폴더 구조

```
src/
  core/     전역 상태, 루프(히트스톱·슬로모션), 입력, 소리, 저장, 스크립트 대기
  render/   종이 인형 빌보드, 임시 그림 화가, 효과(파티클·예고·숫자), 3D 소품, 카메라
  game/     월드(걷기 영역·충돌), 플레이어, 적·보스, 아이템, NPC, 능력치, 목표 화살표
  ui/       HUD, 대화창(읽어주기), 화면들(타이틀·지도·레벨업·결과·그림책·상점·엔딩), CSS
  stages/   hub(마을) · prologue · labor01~12 — 아이 시나리오를 그대로 따르는 스크립트
  data/     스프라이트 정의, 인물, 12과업 정보(대사·보상), 카드
  dev/      갤러리, 테스트 봇
public/assets/  Codex가 넣는 그림·소리 (manifest.json 에 등록)
```
