# Codex에 붙여 넣을 프롬프트 — 2차 애셋 (보스 · 중간 보스 · 과업 짐승)

아래 `---` 사이 내용을 그대로 Codex에 붙여 넣으세요.

---

이 저장소는 초등 저학년용 2.5D 액션 RPG "헤라클레스의 열두 별"이야. 1차 애셋(헤라클레스 3종 · 무기 6종 · UI 아이콘 17종)은 이미 `public/assets/sprites/` 에 들어가 있고 게임에서 잘 보여. 이번엔 **2차: 12과업의 보스와 주요 짐승 25장**을 같은 스타일로 만들어 넣어 줘. 게임 코드는 고치지 마.

## 먼저 읽을 것
1. `AGENTS.md` — 작업 규칙 ("애셋 작업 규칙")
2. `docs/ASSET_SPEC.md` — 스타일 · 규격 · 등록 방법
3. `src/data/sprites.js` — 이번 id들의 비율(w:h)과 게임 속 키(worldH)
4. **스타일 기준 그림**: `public/assets/sprites/hercules_lion.png` 를 열어서 외곽선 굵기, 채색, 눈 모양, 하이라이트를 똑같이 맞춰. 보스들이 헤라클레스 옆에 서도 한 그림책에서 나온 것처럼 보여야 해.

## 꼭 지킬 규칙
- 투명 PNG, 반투명 그림자·글로우·흐린 가장자리 금지 (게임이 알파 0.45 미만을 잘라냄)
- 굵은 짙은 갈색 외곽선 `#3a2618`, 평면 채색 + 흰 하이라이트 1개, 큰 눈 + 볼터치
- **무섭지 않게**: 피·이빨 가득한 입·상처 금지. 화난 눈썹 정도로만 "센 보스" 느낌. 아이가 보고 웃을 수 있어야 해
- **바닥 기준점**: 발(또는 몸의 가장 아래)이 그림 아래 가장자리 가운데에 닿게
- **네발짐승은 옆모습, 오른쪽을 봄** (머리가 오른쪽). 게임이 왼쪽으로 갈 때 뒤집음
- **대화창 얼굴 자르기**: 네발짐승은 그림의 **오른쪽 위 1/4 영역**(가로 50~100%, 세로 0~62%)이 대화창 얼굴로 잘려 나가니까 **머리를 오른쪽 위에** 그려
- **"어질어질" 변형**(`_dizzy`)은 원본과 **자세·크기·위치가 똑같고 눈만 빙글빙글 소용돌이**로. 머리 위 별은 게임이 따로 그리니까 **그림에 별을 넣지 마**
- 같은 짐승의 두 장(예: `bull` / `bull_dizzy`)은 겹쳐 놓으면 눈만 다르게 보일 정도로 맞춰 (게임이 그림을 바꿔 끼움)
- 크기: 1:1 은 512×512, 5:4 는 640×512 (비율은 `sprites.js` 기준, 남는 곳은 투명)
- 투명 배경을 못 만들면 `#00FF00` 배경으로 만든 뒤 Python(Pillow)으로 지우고 초록 테두리가 남지 않게 정리

## 넣는 곳 · 등록
- 파일: `public/assets/sprites/<id>.png` (예: `public/assets/sprites/lion.png`)
- 등록: `public/assets/manifest.json` 의 `"sprites"` 에 25개 추가 (1차 26개는 그대로 두고, 올바른 JSON 유지)
- `src/` 아래 코드는 수정하지 마

## 확인 방법
1. `npm run dev`
2. `http://localhost:5173/?gallery` — 이번 25장 포함 51장이 초록 테두리인지, 가장자리에 초록/흰 찌꺼기가 없는지
3. `_dizzy` / `_calm` / `_happy` / `_tired` / `_down` 짝을 갤러리에서 나란히 보고 크기·위치가 맞는지
4. 게임 속 확인 (봇이 자동으로 보스까지 가 줌, `god` = 무적):
   - 사자 `?stage=labor01&auto&god&bot` · 히드라·게 `labor02` · 사슴 `labor03` · 멧돼지 `labor04` · 대장 새 `labor06` · 황소 `labor07` · 디오메데스·암말 `labor08` · 히폴리테 `labor09` · 오르트로스·게리온 `labor10` · 독수리·라돈 `labor11` · 케르베로스 `labor12`
   - 보스가 땅에 발을 붙이고 서 있는지, 헤라클레스와 크기 차이가 자연스러운지, 왼쪽으로 돌 때 어색하지 않은지
5. 브라우저 콘솔에 `[assets] 불러오기 실패` 경고가 없어야 해

## 끝나면 알려 줘
- 만든 파일 목록과 manifest 변경 내용
- `?gallery` 화면 캡처 (가능하면)
- 스타일이나 무서움 정도가 애매했던 그림, 내가 정해 줘야 할 것
