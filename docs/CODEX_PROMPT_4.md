이 저장소는 초등 저학년용 2.5D 액션 RPG "헤라클레스의 열두 별"이야. 이야기 장면에서는 **그림책**이 한 장씩 넘어가고, 그림 아래에 글이 나오고 목소리로 읽어 줘. 지금은 코드로 그린 임시 그림이 나와. 이번엔 **4차: 그림책 컷신 28장**(프롤로그 9 · 엔딩 5 · 과업 뒷이야기 14)을 그려 넣어 줘. 게임 코드는 고치지 마.

## 먼저 읽을 것
1. `AGENTS.md` — 작업 규칙
2. `docs/ASSET_SPEC.md` — "그림책 컷신" 표, 스타일 규칙
3. **장면마다 읽어 줄 글** (그림이 이 글과 맞아야 해)
   - 프롤로그: `src/stages/prologue.js` 의 `art: 'p_...'` 줄
   - 뒷이야기: `src/data/labors.js` 의 `side` / `prelude` → `pages`
   - 엔딩: `src/stages/hub.js` 의 `ending()` 안 `art: 'e_...'` 줄
4. 지금 임시 그림: `npm run dev` → `http://localhost:5173/?gallery` 맨 아래 16:9 장면들 (구도 참고용, 더 좋게 바꿔도 돼)
5. 스타일 기준 그림: `public/assets/sprites/hercules_lion.png`, `hercules.png`, `cerberus_happy.png`, `deer.png`

## 규격 (꼭 지킬 것)
- **정확히 16:9, 1280×720**. 게임이 16:9 액자에 꽉 채워 늘려 넣으니까 비율이 다르면 찌그러져
- **JPG(품질 85~90), 장당 400KB 이하**. 휴대폰이 게임을 켤 때 그림을 미리 받으니까 가벼워야 해
- 파일: `public/assets/story/<id>.jpg`
- **투명 아님**: 하늘·땅까지 꽉 찬 배경 그림
- **그림 안에 글자 금지**: 글자·숫자·그리스 문자·간판·말풍선 모두 X (글은 게임이 그림 아래에 따로 써 줘)
- **휴대폰에서 작게 보여** (가로 화면에서 그림 폭이 약 480px): 주인공은 크게, 한 장면에 인물 1~3명, 배경은 단순하게. 작은 소품이 많으면 안 보여
- 액자 모서리가 둥글게 잘리니까 **중요한 것은 가운데 80% 안에**. 네 귀퉁이에는 하늘·풀·구름만

## 스타일
- 1~3차 스프라이트와 **한 그림책에서 나온 것처럼**: 굵은 짙은 갈색 외곽선 `#3a2618`, 평면 채색 + 흰 하이라이트 1개, 2~2.5등신 치비, 큰 눈 + 볼터치
- 배경은 외곽선을 조금 가늘게, 부드러운 그러데이션 하늘은 괜찮아
- 팔레트(`docs/GAME_DESIGN.md` 7장): 에게해 파랑 `#3a8fd8`, 올리브 초록 `#7fae4a`, 테라코타 `#d9774b`, 대리석 흰색 `#f4efe4`, 황금 `#f5c542`, 밤하늘 남색 `#1d2350`
- **무섭지 않게**: 피·상처·해골·낫·무기에 맞는 순간 금지. 괴물도 동글동글하고 귀엽게(화난 눈썹 정도). 슬픈 장면도 부드러운 색으로

## 등록
`public/assets/manifest.json` 의 `"story"` 에 추가 (다른 키는 그대로):
```json
"story": {
  "p_birth": "story/p_birth.jpg",
  "p_milkyway": "story/p_milkyway.jpg"
}
```
28장을 한 번에 못 끝내면 **위 묶음(1 → 2 → 3)이 끝날 때마다 등록**해 줘. 등록 안 된 장면은 임시 그림이 나오니까 중간에 멈춰도 게임은 돌아가.

## 확인 방법
1. 파일마다 크기가 정확히 1280×720 인지, 400KB 이하인지 (Python Pillow로 한꺼번에 확인)
2. `http://localhost:5173/?gallery` 맨 아래 장면들이 새 그림으로 바뀌었는지, 찌그러지지 않았는지
3. `http://localhost:5173/?stage=prologue` 에서 그림책을 넘기며 그림과 아래 글이 맞는지
