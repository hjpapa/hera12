# Codex에 붙여 넣을 프롬프트 — 3차 애셋 (헤라클레스 뒷모습·옆모습 + 뒷이야기 인물)

아래 `---` 사이 내용을 그대로 Codex에 붙여 넣으세요. (2차 보스 작업이 끝난 뒤에 진행)

---

이 저장소는 초등 저학년용 2.5D 액션 RPG "헤라클레스의 열두 별"이야. 게임이 이제 **걷는 방향에 따라 헤라클레스의 앞·뒤·옆 그림을 바꿔 끼워**. 지금은 앞모습만 있어서 위로 걸을 때도 얼굴이 보이고 어색해. 이번엔 **3차: 헤라클레스 뒷모습·옆모습 4장 + 새로 추가된 신화 이야기 인물 15장**을 만들어 줘. 게임 코드는 고치지 마.

## 먼저 읽을 것
1. `AGENTS.md` — 작업 규칙
2. `docs/ASSET_SPEC.md` — "플레이어 뒷모습 · 옆모습", "뒷이야기 인물" 표
3. `src/data/sprites.js` — 이번 id들의 비율과 `hand`(손 위치)
4. 스타일 기준: `public/assets/sprites/hercules_lion.png`, `hercules.png`

## A. 헤라클레스 4장 (가장 중요, 512×512 투명 PNG)
**앞모습 그림과 같은 캐릭터·같은 키·같은 발 위치**여야 해. 게임이 걷는 중에 그림을 바꿔 끼우니까, 겹쳐 놓았을 때 발바닥 높이·머리 높이·몸 크기가 같아야 자연스러워.
- `hercules_lion_back.png` — 사자 망토 헤라클레스 **뒷모습**. 사자 머리 망토의 뒤통수와 귀, 갈기가 어깨를 덮고 사자 가죽이 등 뒤로 망토처럼 내려옴. 얼굴은 안 보임. 두 팔은 자연스럽게 옆으로
- `hercules_lion_side.png` — 사자 망토 헤라클레스 **옆모습, 오른쪽을 봄**. 걷는 중인 자세(한 발 앞으로), 망토가 뒤로 살짝 날림. 큰 눈 하나와 볼터치가 보임
- `hercules_back.png` — 망토 없는 기본 헤라클레스 뒷모습 (곱슬머리 뒤통수, 빨간 머리띠 매듭이 뒤에서 보임, 키톤 등판)
- `hercules_side.png` — 망토 없는 기본 헤라클레스 옆모습, 오른쪽을 봄, 걷는 자세
- 손에는 아무것도 들지 않음. 무기는 게임이 손 위치에 붙여:
  - 뒷모습: 가로 70%, 아래에서 30% 지점 (오른손)
  - 옆모습: 가로 60%, 아래에서 30% 지점 (앞쪽 손)

## B. 신화 이야기 인물 15장 (그림책·대사용, 1:1 = 512×512, `chiron` 만 5:4 = 640×512)
| id | 설명 |
|---|---|
| `apollo` | 아르테미스의 쌍둥이 동생: 금빛 곱슬머리, 월계관, 흰 옷, 주황 망토, 활 |
| `theseus` | 아테네의 영웅: 금발 짧은 머리, 파란 옷, 빨간 망토, 걱정스러운 얼굴 (의자에 붙어 버림) |
| `theseus_free` | 같은 인물, 풀려나서 활짝 웃음 |
| `alcestis` | 왕비: 하늘색 베일, 흰 드레스, 다정한 미소 |
| `admetus` | 아드메토스 왕: 보라 로브, 왕관, 짧은 수염 |
| `thanatos` | 죽음의 신이지만 **절대 무섭지 않게**: 검은 옷, 하얀 날개, 눈 감은 조용한 얼굴 (해골·낫 금지) |
| `hesione` | 트로이의 공주: 분홍 드레스, 작은 왕관, 손목에 가벼운 사슬 |
| `sea_monster` | 트로이의 바다 괴물: 파란 뱀머리 + 아래로 이어지는 목 (`hydra_head` 와 같은 구도), 동글동글 |
| `cacus` | 불 뿜는 꾀 많은 거인: 코에서 연기, 능글맞은 웃음, 거인 체형 |
| `antaeus` | 리비아의 씨름꾼 거인: 모래빛 피부, 근육, 자신만만한 표정, 거인 체형 |
| `arete` | 갈림길의 "옳은 길" 여인: 흰 옷, 월계관, 따뜻하고 단단한 미소 |
| `kakia` | 갈림길의 "쉬운 길" 여인: 분홍 드레스, 꽃장식, 사탕·과일을 들고 신나게 웃음 (나쁜 사람처럼 X, 그냥 놀기 좋아함) |
| `chiron` | 지혜로운 켄타우로스 스승: 흰 수염, 회색 말 몸, 오른쪽을 봄 (5:4) |
| `hercules_baby` | (이미 있음, 교체 원하면) 아기 헤라클레스 |
| `pythia` | (이미 임시 그림) 델포이의 무녀: 베일, 월계관, 눈 감음 |

## 규칙
- 1차·2차와 같은 스타일: 굵은 짙은 갈색 외곽선 `#3a2618`, 평면 채색 + 하이라이트 1개, 큰 눈 + 볼터치
- 투명 배경, 반투명 그림자·글로우 금지 (알파 0.45 미만은 잘림)
- 사람은 정면(살짝 오른쪽) 또는 오른쪽, 발이 그림 아래 가운데에 닿게
- 무섭지 않게: 피·해골·무기에 다친 모습 금지
- 등록: `public/assets/manifest.json` 의 `"sprites"` 에 추가 (기존 키 유지)

## 확인 방법
1. `npm run dev` → `http://localhost:5173/?gallery` 에서 새 그림 초록 테두리 확인
2. `http://localhost:5173/?stage=labor01&god` 에서 방향키 ↑ → 뒷모습, ← → → 옆모습, ↓ → 앞모습으로 바뀌는지, 바뀔 때 키·발 위치가 튀지 않는지, 몽둥이가 손에 붙어 있는지 확인
3. 새 이야기 인물은 그림책(`?gallery` 아래쪽 장면들)과 과업 3(아폴론), 과업 12(테세우스)에서 보임
