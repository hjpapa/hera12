# 🎮 헤라클레스의 열두 별 — 게임 디자인 문서

## 1. 핵심 컨셉

| 항목 | 내용 |
|---|---|
| 장르 | 3인칭 액션 RPG (스테이지형 + 마을 허브 월드) |
| 대상 | 초등 저학년 (7~9세), 부모와 함께 해도 재미있게 |
| 플랫폼 | 휴대폰 웹 브라우저 **전체 화면** (가로 권장, 세로도 지원) · PC 브라우저 |
| 플레이 시간 | 과업 하나에 5~10분, 전체 약 2~3시간 + 별 모으기 |
| 비주얼 | **2.5D**: 장난감 디오라마 같은 귀여운 **3D 월드** + 종이 인형 같은 **2D 캐릭터**(빌보드) |
| 핵심 재미 | ① 쉬운 조작으로 느끼는 **화끈한 타격감** ② 과업마다 새 장비·기술·외형이 생기는 **성장** ③ 별 12개를 모아 별자리를 완성하는 **수집과 성취** |

### 디자인 원칙 — "쉽지만 시시하지 않게"
1. **버튼은 최대 3개 + 조이스틱 1개.** 나머지는 상황에 따라 큰 버튼이 알아서 바뀜 (공격 → 말하기 → 꽉 잡기 → 안아 주기).
2. **실패가 벌이 아니다.** 하트가 다 떨어지면 "앗, 잠깐 쉬자!" 하고 가까운 체크포인트에서 바로 다시 시작. 보스 체력은 그대로 유지.
3. **모든 공격은 미리 알려 준다.** 적이 공격하기 전에 땅에 빨간 원/화살표가 0.6~1초 동안 차오름 → 아이가 "보고 피하는" 재미.
4. **글을 몰라도 된다.** 모든 대사 읽어주기(음성), 목표는 노란 화살표로 안내, 아이콘 위주 UI.
5. **칭찬을 아끼지 않는다.** 콤보, 레벨업, 숨은 보물, 별 획득마다 크고 반짝이는 연출.

## 2. 조작 (모바일 터치)

```
┌──────────────────────────────────────────────────────────┐
│ ❤❤❤❤❤❤  Lv.3 ▓▓▓▓░░░        [목표: 사자를 찾아라 ➜]    ⏸ │
│                                                          │
│                                                          │
│                    (3D 월드 + 캐릭터)                      │
│                                                          │
│                                              [🏹 스킬]    │
│   ◯  ← 왼쪽 아무 곳이나 터치하면                [💨]  ( 👊 ) │
│  (●)    그 자리에 조이스틱이 생김                     큰 버튼  │
└──────────────────────────────────────────────────────────┘
```

| 입력 | 동작 | 비고 |
|---|---|---|
| **왼쪽 화면 드래그** | 이동 (플로팅 조이스틱) | 손가락을 놓은 곳이 중심. 살짝 밀면 걷기, 끝까지 밀면 달리기 |
| **큰 버튼 (👊)** | 공격 / 상황 행동 | 톡톡톡 = 3단 콤보. NPC 근처 = 💬 말하기, 보스 기절 = ✊ 꽉 잡기 |
| **💨 버튼** | 구르기(대시) | 구르는 동안 무적. 적 공격 피하기 |
| **스킬 버튼** | 현재 스킬 (독화살 / 딸랑이 / 창) | 자동 조준. 쿨타임은 버튼 테두리 링으로 표시 |
| 스킬 버튼 옆 작은 ↻ | 스킬 바꾸기 | 스테이지 시작 시 그 과업에 맞는 스킬로 자동 선택 |
| **별 버튼 (필살기)** | 헤라클레스 강타 | 테두리 게이지가 가득 차면 반짝반짝 → 누르면 하늘로 뛰어올라 주변 모든 적을 쾅! |
| 화면 아무 곳 탭 | 대화 넘기기 | |

**PC 키보드 (테스트·부모용)**: 이동 `WASD/방향키` · 공격 `J/Space` · 구르기 `K/Shift` · 스킬 `L` · 스킬 바꾸기 `Q` · 필살기 `E` · 대화 `Enter/Space` · 일시정지 `Esc`
**게임패드**: 왼쪽 스틱 이동, A 공격, B 구르기, X 스킬, Y 바꾸기

### 아이를 위한 조작 보조
- **자동 조준(에임 어시스트)**: 공격 버튼을 누르면 앞쪽 120° · 4m 안의 가장 가까운 적을 향해 몸을 돌리고 살짝 다가가며 때림. 방향 조작이 서툴러도 맞음.
- **입력 버퍼**: 공격 중에 미리 누른 버튼을 기억했다가 다음 공격으로 자연스럽게 이어 줌 (0.25초).
- **넉넉한 판정**: 플레이어 피격 판정은 몸보다 작게, 공격 판정은 몽둥이보다 크게.
- **자동 회복**: 전투가 끝나고 5초가 지나면 하트 반 칸씩 천천히 회복.
- **공격 차례**: 여러 마리가 한꺼번에 덤비지 않게, 동시에 공격하는 일반 적은 최대 2마리(보스전·도움 모드에서는 1마리). 공격을 시작하는 사이에는 0.45초 간격. 차례를 기다리는 적은 조금 떨어져서 플레이어 둘레를 돈다.
- **도움 모드**: 같은 과업에서 두 번 쓰러지면 부엉이가 "내가 도와줄까?" 하고 한 번 물어봄. 켜면 적의 공격 예고 1.35배 길게, 공격 사이 쉬는 시간 1.4배, 적이 받는 피해 1.25배, 동시에 공격하는 적 1마리. 부모님 메뉴의 "항상 도움 모드"로 처음부터 켤 수도 있음.
- **레벨업 카드**: 공격·구르기를 멈추고 0.8초가 지나야 카드 창이 뜨고, 뜬 뒤 0.6초 동안은 터치를 받지 않음 (공격 버튼을 누르던 손가락이 카드를 잘못 고르지 않게).

## 3. 타격감 설계 (수치 기준)

> 타격감 = **멈춤(히트스톱) + 흔들림(셰이크) + 번쩍임(플래시) + 밀려남(넉백) + 소리 + 진동 + 파티클**. 일곱 가지가 **같은 프레임에** 동시에 터져야 "퍽!" 하고 느껴진다.

### 3단 콤보 (몽둥이)

| | 1타 (가로 휘두르기) | 2타 (반대로 휘두르기) | 3타 (내려찍기) |
|---|---|---|---|
| 동작 시간 | 0.30초 | 0.30초 | 0.46초 |
| 판정 발생 | 0.07초 | 0.07초 | 0.15초 |
| 피해 배율 | ×1.0 | ×1.0 | ×2.0 + 주변 충격파 |
| 히트스톱 | 0.05초 | 0.05초 | 0.11초 |
| 화면 흔들림 | 약 | 약 | 강 |
| 넉백 | 3 | 3 | 9 (+공중에 살짝 뜸) |
| 앞으로 내딛기 | 0.35m | 0.35m | 0.6m |

### 공통 연출
- **히트스톱**: 맞은 순간 게임 시간을 0.05~0.12초 정지 (치명타 +0.03초, 처치 +0.06초). 화면 흔들림은 멈춤 중에도 계속 → 묵직함.
- **적 피격**: 0.1초 하얗게 번쩍 → 몸이 납작해졌다가(스쿼시) 튕겨 돌아옴, 뒤로 밀려남.
- **데미지 숫자**: 맞은 자리에서 톡 튀어 오름. 일반=흰색, **치명타=노란색 크게 + "치명타!"**, 독=초록색, 0 데미지 대신 "쿵!" 같은 의성어.
- **파티클**: 별 모양 스파크 6~10개, 3타는 흙먼지 링 + 충격파 원.
- **처치**: 적이 빙글 돌며 작아지다가 **별가루 펑!** → 경험치 구슬과 동전이 톡톡 튀어나와 플레이어에게 쏙쏙 빨려 옴 (빨려 올 때마다 음이 한 칸씩 올라감 → 기분 좋음).
- **보스 처치**: 0.3배속 슬로모션 1.2초 + 카메라 줌인 + 큰 별가루 폭발 + "과업 성공!" 배너.
- **진동**: 안드로이드에서 1·2타 12ms, 3타 25ms, 피격 40ms, 보스 처치 패턴 진동. (설정에서 끄기)
- **사운드**: 휘두르기 "휙" → 타격 "퍽"(저음 쿵 + 노이즈) → 콤보가 이어질수록 음이 조금씩 높아짐.
- **콤보 카운터**: 2.5초 안에 계속 맞히면 "5 콤보! 멋져!", "10 콤보! 대단해!", "20 콤보! 진짜 영웅!"

### 필살기 · 완벽한 회피 (게임성 보강)
| 항목 | 내용 |
|---|---|
| 필살기 게이지 | 때릴 때 +3 (3타·창 +5), 적을 물리치면 +8, 완벽한 회피 +20. 100이 되면 별 버튼이 반짝임. 스테이지가 바뀌어도 이어짐 |
| 헤라클레스 강타 | 0.4초 동안 하늘로 뛰어올랐다가 내려찍기: 반지름 8m 안의 모든 적에게 공격력 ×5, 일반 적은 2.2초 기절, 히트스톱 0.14초 + 슬로모션 + 금빛 화면 + 진동 |
| 완벽한 회피 | 구르는(무적) 순간 적의 공격이 닿으면 → 0.55초 슬로모션, "완벽한 회피!", 구르기 쿨타임 초기화 (독 웅덩이처럼 계속 닿아 있는 피해는 구르면 안 맞지만 완벽한 회피로 치지 않음) |
| 결과 기록 | 과업 결과 화면에 최고 콤보 · 물리친 적 · 모은 동전, 최고 콤보를 넘으면 "새 기록!" |

### 걷기 · 방향 연출
- 발걸음은 **실제로 움직인 거리**로 계산 → 빨리 달리면 발도 빨라지고, 멈추면 바로 멈춤
- 걸을 때: 한 걸음마다 통통 튀기 + 좌우 뒤뚱 + **다리 부분만 앞뒤로 흔들기**(그림 아래쪽만 휘게 하는 셰이더) + 발 디딜 때 살짝 납작 + 작은 먼지
- 왼쪽↔오른쪽 방향이 바뀌면 **종이 인형이 뒤집히듯** 0.15초 동안 얇아졌다가 펼쳐짐
- 위(화면 안쪽)로 걸으면 **뒷모습**, 옆으로 걸으면 **옆모습**, 아래로 걸으면 앞모습 (Codex 그림 `hercules_lion_back` · `_side` 가 있으면 자동 사용). 가만히 서 있으면 1.4초 뒤 다시 얼굴이 보이게 앞모습
- 적·NPC·동료도 같은 걷기 연출 (네발짐승은 다리 영역을 더 크게)

### 플레이어 피격
- 히트스톱 0.08초 + 강한 흔들림 + 화면 가장자리 빨간 번쩍 + 1초 무적(깜빡깜빡)
- 하트는 반 칸 단위. 보통 적 공격 = 반 칸, 보스 큰 공격 = 한 칸.

### 적 공격 예고 (텔레그래프)
| 공격 종류 | 예고 표시 | 예고 시간 |
|---|---|---|
| 근접 물기/할퀴기 | 적 머리 위 "!" + 발밑 빨간 원이 차오름 | 0.6초 |
| 돌진 | 진행 방향으로 빨간 화살표 띠 | 0.9초 |
| 내려찍기/충격파 | 빨간 원(범위)이 안쪽부터 차오름 | 1.0초 |
| 원거리 투사체 | 땅에 빨간 선 | 0.7초 |
| 급강하(새) | 땅에 그림자가 진해짐 | 0.8초 |

## 4. 카메라

- **고정 각도 3인칭 쿼터뷰** (약 37° 내려다봄). 아이가 카메라를 돌릴 필요 없음.
- 플레이어를 부드럽게 따라감. 진행 방향 쪽을 조금 더 보여 줌.
- **보스전**: 플레이어와 보스가 모두 화면에 들어오도록 자동으로 줌 아웃.
- **컷신**: 대사하는 인물 쪽으로 카메라가 살짝 이동·줌.
- 세로 화면에서는 더 멀리서 넓게 보도록 자동 조정.

## 5. 성장 · 성취 시스템 (RPG 요소)

- 적을 물리치면 경험치 구슬 → 경험치 바가 차면 **레벨 업!** (화려한 연출 + 하트 모두 회복)
- 레벨 업 때 카드 3장 중 하나를 고름: 💪 **힘**(공격력 +) · ❤️ **체력**(하트 +반 칸) · ⚡ **빠르기**(이동 · 구르기 +)

- **영웅의 별** 12개 → 마을 별자리 제단에 하나씩 켜짐 (진행도가 눈에 보임)
- **별자리 · 신화 카드** 15장 → 도감 (신화 공부 효과)
- **드라크마 동전** → 마을 상점: 하트 그릇, 강한 몽둥이, 꿀빵(회복)

## 6. 월드 구조

```
             [프롤로그: 아기 침대] → [티린스 튜토리얼]
                              │
                     ┌────────▼────────┐
                     │  티린스 마을 (허브)  │  ← 왕궁 · 별자리 제단 · 상점 · 이올라오스
                     │  12개 과업의 문     │
                     └────────┬────────┘
     왕과 대화 → 문 열림 → 과업 스테이지 → 보고(왕의 반응) → 별 획득 → 다음 과업
```

- 허브 마을 둘레에 12개의 **과업의 문**이 있고, 문마다 그 지역의 풍경(사자 동굴, 늪, 설산, 바다…)이 미니어처처럼 꾸며져 있음.
- 아직 열리지 않은 문은 구름으로 막혀 있음. 다음 문은 금빛 기둥이 하늘로 솟아 있음.
- 마을 지도(⏸ 메뉴)에서 바로 이동도 가능.

### 스테이지 공통 흐름
1. 도착 배너 "과업 1 · 네메아의 사자"
2. 짧은 길 (일반 적 · 항아리 · 숨은 보물) — 1~3분
3. 과업 고유 장치 (퍼즐 · 미니게임 · 동료)
4. 보스전 — 2~4분
5. 결과 화면: 별 3개 판정, 경험치, 카드 공개 → 마을로 귀환 → 왕의 반응

## 8. 기술 구성

| 항목 | 선택 | 이유 |
|---|---|---|
| 엔진 | **Three.js** (WebGL) + **Vite** | 휴대폰 브라우저에서 설치 없이 바로 실행, 코드만으로 전체 구성 가능 |
| 언어 | JavaScript (ES Modules) | 빌드 단순, Claude/Codex 모두 다루기 쉬움 |
| 전체 화면 | Fullscreen API + 가로 고정 시도 + **PWA(홈 화면에 추가)** | 안드로이드는 버튼 한 번에 전체 화면, 아이폰은 홈 화면에 추가 시 전체 화면 |
| 사운드 | Web Audio API 절차 합성 (기본) + 파일 교체 가능 | 애셋 없이도 소리가 남. Codex가 파일로 교체 |
| 음성 | Web Speech API (`ko-KR`) | 대사 읽어주기 |
| 저장 | localStorage | 진행도·설정 자동 저장 |
| 애셋 | `public/assets/manifest.json` 에 등록된 파일이 있으면 사용, 없으면 코드로 그린 임시 그림 사용 | Claude(코드)와 Codex(애셋) 작업을 완전히 분리 |

### 휴대폰 최적화 (적용됨)
- 120Hz 화면에서도 **최대 60fps** (배터리·발열 절약), 대화·메뉴 중엔 30fps
- **자동 해상도**: 프레임이 느리면 해상도를 0.15씩 낮추고(최저 0.6배), 여유가 생기면 다시 올림. 그래도 느리면 그림자를 끔
- 메모리·코어가 적은 휴대폰은 처음부터 '낮음' 화질, 고해상도 화면은 안티앨리어싱 끔, 휴대폰은 가벼운 그림자 방식
- 스테이지마다 쓰는 그림을 **미리 GPU에 올리고 셰이더를 미리 만들어** 보스가 처음 나올 때 멈칫하지 않게
- 스테이지가 바뀌면 안 쓰는 그림을 GPU에서 내림, 투사체 모양은 한 번만 만들어 복제, 움직이지 않는 소품은 하나로 합쳐 그리기

### 성능 목표
- 중급 안드로이드 폰에서 60fps (최소 30fps)
- 화질 설정: 높음(그림자 + 고해상도) / 보통 / 낮음(그림자 끔, 해상도 1배)
- 드로우콜 150 이하, 스테이지당 텍스처 메모리 40MB 이하
