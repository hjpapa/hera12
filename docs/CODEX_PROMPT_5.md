# Codex에 붙여 넣을 프롬프트 — 5차 애셋 (남은 임시 그림 51장: 인물 · 적 · 물건)

아래 `---` 사이 내용을 그대로 Codex에 붙여 넣으세요.

---

이 저장소는 초등 저학년용 2.5D 액션 RPG "헤라클레스의 열두 별"이야. 지금 게임에는 Codex가 그린 그림과 **코드로 그린 임시 그림이 섞여 있어서** 화면이 들쭉날쭉해. 이번엔 **5차: 아직 임시 그림인 스프라이트 51장**(인물 27 · 적과 동물 16 · 물건 8)을 그려서, 게임에 나오는 그림을 모두 같은 그림책 스타일로 맞춰 줘. 게임 코드는 고치지 마.

## 먼저 읽을 것
1. `AGENTS.md` — 작업 규칙
2. `docs/ASSET_SPEC.md` — 스타일 · 규격 · 등록 방법
3. `src/data/sprites.js` — 이번 id들의 색(`o`), 비율(`w:h`), 게임 속 키(`worldH`)
4. **모습 기준**: 그림책 그림(`public/assets/story/*.jpg`)에 이미 나온 인물은 **그 그림과 같은 얼굴·머리·옷**으로 그려 (아래 표의 "그림책" 칸). 그림책과 스프라이트가 달라 보이면 안 돼
5. 스타일 기준 스프라이트: `hercules_lion.png`, `apollo.png`, `theseus.png`, `cerberus_happy.png`, `stym_leader.png`, `crab_giant.png`
6. 지금 임시 그림: `npm run dev` → `http://localhost:5173/?gallery` (회색 테두리가 이번에 그릴 것)

## 꼭 지킬 규칙 (1~3차와 같음)
- 투명 PNG, 반투명 그림자·글로우·흐린 가장자리 금지 (게임이 알파 0.45 미만을 잘라냄)
- 굵은 짙은 갈색 외곽선 `#3a2618`, 평면 채색 + 흰 하이라이트 1개, 2~2.5등신 치비, 큰 눈 + 볼터치
- **발(몸의 가장 아래)이 그림 아래 가장자리 가운데**에 닿게. 사람은 정면(살짝 오른쪽), 네발짐승·켄타우로스는 **오른쪽을 봄**
- 크기: 사람·새·물건 **512×512**, 네발짐승·두꺼비·게·켄타우로스 **640×512**(5:4), 방패 `w_shield` 만 **256×512**
- **대화창 얼굴**: 사람은 그림 위쪽(가로 12~88%, 세로 0~62%), 네발짐승은 오른쪽 위(가로 50~100%, 세로 0~62%)가 잘려서 대화창 얼굴이 돼. 얼굴을 그 안에 크고 또렷하게
- 손에 든 물건(지팡이·창·횃불 등)은 **그림에 같이 그려** (헤라클레스와 달리 게임이 따로 붙이지 않아). 단, 아래에 "그리지 마"라고 한 것은 빼
- **무섭지 않게**: 피·상처·이빨 가득한 입 금지. 적도 동글동글, 화난 눈썹 정도. 저승 인물도 다정하게
- 두 장이 한 쌍인 것(`snake`/`snake_dizzy`, `prometheus`/`prometheus_free`, `atlas`/`atlas_free`)은 **같은 크기·같은 발 위치**로 (게임이 그림을 바꿔 끼움)
- 투명 배경을 못 만들면 `#00FF00` 배경으로 만든 뒤 Python(Pillow)으로 지우고 초록 테두리가 남지 않게 정리

## 등록
`public/assets/manifest.json` 의 `"sprites"` 에 추가 (기존 키는 그대로):
```json
"glau": "sprites/glau.png",
"eurystheus": "sprites/eurystheus.png"
```
한 번에 못 끝내면 **A → B → C 묶음이 끝날 때마다 등록**해 줘. 등록 안 된 것은 임시 그림이 나오니까 중간에 멈춰도 게임은 돌아가.

## 확인 방법
1. `http://localhost:5173/?gallery` — 이번 51장이 모두 초록 테두리가 됐는지, 이미 있는 그림들과 나란히 놓아 스타일이 같은지
2. 그림책과 비교: 위 표 "그림책" 칸의 장면과 얼굴·옷 색이 같은지
3. 게임 안에서:
   - `?stage=hub&god` — 마을 사람들, 부엉이, 연습 인형, 대화창 얼굴
   - `?stage=labor09&god` — 아마존 전사·궁수, 변장한 헤라
   - `?stage=labor11&god` — 네레우스, 프로메테우스와 사슬, 아틀라스 (손 위의 하늘 공과 손바닥 위치가 맞는지)
   - `?stage=labor12&god` — 헤르메스, 카론, 하데스, 페르세포네, 박쥐, 뼈다귀 병사와 방패 (방패가 두 개로 보이지 않는지)
4. 그림 크기·투명도 확인 (Pillow): 크기가 규격대로인지, 알파가 0 또는 255 뿐인지
