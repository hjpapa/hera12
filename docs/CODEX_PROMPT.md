# Codex에 붙여 넣을 프롬프트 — 1차 애셋 (헤라클레스 · 무기 · UI 아이콘)

아래 `---` 사이 내용을 그대로 Codex에 붙여 넣으세요.

---

이 저장소는 초등 저학년용 2.5D 액션 RPG "헤라클레스의 열두 별"이야. 게임 코드는 완성돼 있고, 지금 그림은 전부 코드로 그린 임시 그림이야. 너의 일은 **1차 그림 애셋을 PNG로 만들어 넣는 것**이야. 게임 코드는 고치지 마.

## 먼저 읽을 것
1. `AGENTS.md` — 작업 규칙 (특히 "애셋 작업 규칙")
2. `docs/ASSET_SPEC.md` — 스타일 · 규격 · 등록 방법 전체
3. `src/data/sprites.js` — 스프라이트 id, 비율(w:h), 게임 속 키(worldH)

## 이번에 만들 것 (총 26개)

### A. 헤라클레스 3종 (512×512, 투명 PNG)
같은 캐릭터라서 **얼굴·몸·옷이 세 장 모두 똑같아야 해.** `hercules_lion` 을 먼저 만들어서 스타일 기준으로 삼고, 나머지 두 장을 거기에 맞춰.
- 공통 디자인: 2.2등신 꼬마 영웅, 햇볕에 그을린 피부, 갈색 곱슬머리, 빨간 머리띠, 한쪽 어깨 끈의 흰 키톤(금색 테두리), 갈색 가죽 허리띠, 갈색 샌들, 근육이 살짝 보이는 굵은 팔, 큰 눈(흰 하이라이트 2개) + 분홍 볼터치 + 자신감 있는 미소
- `hercules_lion.png` — 위 모습에 **네메아 사자 가죽 망토**: 황금빛 사자 얼굴이 모자처럼 머리 위에 얹혀 있고(귀·코가 보임), 갈기가 어깨를 감싸고, 가죽이 등 뒤로 망토처럼 내려옴. 머리띠는 사자 모자에 가려져도 됨. **게임에서 가장 오래 보이는 그림**이니 가장 공들여.
- `hercules.png` — 사자 망토 없는 기본 모습 (빨간 머리띠가 보임)
- `hercules_hold.png` — 사자 망토 버전이 **두 팔을 머리 위로 쭉 뻗어** 무언가 무거운 걸 떠받치는 자세. 얼굴이 빨갛고 이마에 땀방울, 이를 악물고 웃음 (하늘을 떠받치는 장면용)
- 셋 다 **손에 아무것도 들지 않음** (무기는 따로 붙음)

### B. 무기 6종 (256×512, 세로로 긴 투명 PNG)
게임이 그림의 **아래쪽 가운데를 축으로 회전**시켜 휘두르니까, 손잡이 끝이 정확히 아래쪽 가운데에 오고 무기가 위로 곧게 뻗어야 해.
- `w_club.png` — 굵은 나무 몽둥이 (위로 갈수록 두꺼움, 옹이 몇 개, 손잡이에 금색 띠)
- `w_spear.png` — 나무 자루 + 은빛 창끝, 창끝 밑에 금색 띠
- `w_bow.png` — 나무 활 (활대가 위아래로, 흰 시위)
- `w_rattle.png` — 청동 딸랑이 (짧은 나무 손잡이 + 위쪽에 청동 방울/짝짝이 두 개)
- `w_torch.png` — 나무 횃불 + 주황·노랑 불꽃 (불꽃도 반투명 없이 단단한 색으로)
- `w_fist.png` — 아래쪽에 꽉 쥔 주먹 하나만 (위쪽은 비워 둠)

### C. UI 아이콘 17종 (256×256, 투명 PNG, 파일 이름 `icon_<이름>.png`)
아이가 엄지로 누르는 둥근 버튼 안에 들어가. 버튼 배경색은 게임이 칠하니까 **아이콘만, 가운데 꽉 차게, 굵은 외곽선**으로. 글자 넣지 마.
`attack`(비스듬한 몽둥이) · `fist`(주먹) · `dash`(휙 부는 바람 세 줄) · `bow`(활과 초록 독화살촉) · `rattle`(청동 딸랑이 + 소리 선) · `spear`(비스듬한 창) · `swap`(동그랗게 도는 화살표 ↻) · `talk`(점 세 개 말풍선) · `grab`(꽉 쥐는 손 + 힘 표시) · `hug`(분홍 하트) · `torch`(횃불) · `push`(큰 바위 + 오른쪽 노란 화살표) · `heart`(빨간 하트) · `star`(금빛 별) · `coin`(드라크마 금화, Δ 무늬) · `pause`(두 줄) · `apple`(황금사과 + 초록 잎)

## 그림 규칙 (반드시)
- 스타일: 귀여운 종이 인형 · 그림책. **굵은 짙은 갈색 외곽선 `#3a2618`** (512px 기준 6~8px), 평면 채색 + 흰 하이라이트 1개, 그라데이션 최소
- 팔레트: 에게해 파랑 `#3a8fd8`, 올리브 `#7fae4a`, 테라코타 `#d9774b`, 대리석 `#f4efe4`, 황금 `#f5c542`
- **투명 배경**. 게임이 알파 0.45 미만을 잘라내니까 **반투명 그림자 · 글로우 · 흐린 가장자리 금지**, 가장자리는 깔끔하게
- 캐릭터: 정면 또는 살짝 오른쪽을 봄 (왼쪽은 게임이 뒤집음). **발바닥이 그림 아래 가장자리 가운데에 닿게**, 위·좌우 여백은 조금만
- 피·무서운 표정 금지
- 이미지 생성 도구가 투명 배경을 못 만들면 단색 크로마키(`#00FF00`) 배경으로 만든 뒤 Python(Pillow)으로 배경을 지우고, 초록 테두리가 남지 않게 정리해. 마지막에 지정된 크기로 맞추되 비율은 유지하고, 남는 곳은 투명으로 채워.

## 넣는 곳 · 등록
- 파일: `public/assets/sprites/` 에 위 이름 그대로 (예: `public/assets/sprites/hercules_lion.png`, `public/assets/sprites/icon_attack.png`)
- 등록: `public/assets/manifest.json` 의 `"sprites"` 에 추가 (기존 키는 지우지 말고, 올바른 JSON 유지)
  ```json
  "sprites": {
    "hercules_lion": "sprites/hercules_lion.png",
    "w_club": "sprites/w_club.png",
    "icon_attack": "sprites/icon_attack.png"
  }
  ```
- `src/` 아래 코드는 수정하지 마.

## 확인 방법
1. `npm install` (처음 한 번) → `npm run dev`
2. `http://localhost:5173/?gallery` — 새로 넣은 그림은 **초록 테두리**로 보여. 26개가 모두 초록인지, 체크무늬 배경 위에서 테두리에 초록/흰 찌꺼기가 없는지 확인
3. `http://localhost:5173/?stage=labor01&god` — 몽둥이를 휘둘러서(J 또는 스페이스 키 3번) 몽둥이가 **손에 붙어서 자연스럽게 회전**하는지, 캐릭터 발이 땅에 붙어 있는지 확인. 버튼 아이콘이 잘 보이는지도 확인
4. `http://localhost:5173/?stage=labor11&god&auto` 로 하늘 들기 장면에서 `hercules_hold` 확인 (가능하면)
5. 브라우저 콘솔에 `[assets] 불러오기 실패` 경고가 없어야 해

## 끝나면 알려 줘
- 만든 파일 목록과 manifest 변경 내용
- `?gallery` 화면 캡처 (가능하면)
- 스타일을 맞추기 어려웠던 그림이나, 다음 차례(보스 · 적 · NPC)로 넘기기 전에 내가 정해 줘야 할 것
